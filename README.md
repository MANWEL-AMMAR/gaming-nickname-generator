# Gaming Nickname Generator 🎮

My second Python project.

This program asks the user for their nickname and favorite game, then generates five creative gaming nickname ideas.

## Features

* User input
* Generates 5 gaming nickname ideas
* String concatenation
* Console output

## Example

**Input**

```
Nickname: Manwel
Favorite Game: Minecraft
```

**Output**

```
1. Manwel Minecraft
2. The King of Minecraft
3. The Legend of Minecraft
4. Minecraft Master
5. Minecraft Manwel
```
